# Urban Textiles

Urban Textiles is a Durban-based textile and sewing business website offering quality fabrics, sewing patterns, sewing accessories, and hands-on sewing classes.

## About the Website

The website was created for Urban Textiles, a creative textile hub founded in 2022 by two fashion graduates. Its mission is to provide quality fabrics, modern sewing patterns, and accessible sewing education to the Durban community.

## Website Pages

- **Homepage (`index.html`)** – Introduces Urban Textiles and provides an overview of its products and sewing classes.
- **About Us (`about.html`)** – Provides information about the company, its mission, vision, and services.
- **Shop Online (`shop.html`)** – Displays products including premium cotton, dress pattern packs, and a notions kit.
- **Workshops and Classes (`workshops.html`)** – Shows the weekly class schedule and explains what students learn.
- **Book a Class (`book.html`)** – Provides an online form for visitors to book a sewing class.
- **Contact and Location (`contact.html`)** – Provides the business address, phone number, email address, trading hours, location information, and a contact form.

## Classes

Urban Textiles offers classes six days a week:

| Class | Time | Days |
|---|---|---|
| Beginners Class | 10:00–12:00 | Monday–Saturday |
| Moderate Learning Class | 14:00–16:00 | Monday–Saturday |

The Beginners Class covers basic sewing machine skills, threading, straight stitching, and simple projects. The Moderate Learning Class covers pattern cutting, garment construction, hems, zippers, and other advanced techniques.

All materials are included for a student's first class.

## Getting Started

No build tools or dependencies are required.

1. Keep all HTML files in the same project folder.
2. Keep the `pictures Lisasline` image folder in the same project directory.
3. Open `index.html` in a web browser.
4. Use the navigation menu to move between the pages.

## Notes

The current booking, shopping cart, and contact forms are front-end forms only. No server-side processing or database integration is included in the supplied HTML files.
